#### 緊急事態 (Emergencies) {#emergencies}

| メッセージ | 意味と対処法 |
|------------|--------------|
| 熱っぽくなった。 | 獣人（ウェアモンスター）からの獣化症（ライカンスロープ）感染です。聖水を *飲む*、トリカブトを食べる、または祈り（`#pray`）を捧げましょう。 |
| 体の動きが遅くなった。 | 肉体が石へと変化しています（石化進行中）。即座にトカゲの死体を食べる、酸の薬を飲む、または祈り（`#pray`）を捧げてください。 |
| 体が緑色のスライムに変化しつつある。 | 緑のスライムによるスライム化感染です。火で焼き払う（火の巻物を読む、自身に火球の呪文を唱える、あるいは火の杖を自分に振る）、または祈り（`#pray`）を捧げてください。 |
| 死ぬほど気分が悪い。 | 致死性の病気（ペスティレンスやデモゴルゴン等による攻撃）です。超回復の薬を飲む、ユーカリの葉を食べる、病気治療の呪文を唱える、または祈り（`#pray`）を捧げてください。 |
