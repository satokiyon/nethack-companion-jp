#### フロアの環境音 (Level Ambience) {#level-ambience}

| メッセージ                                       | 意味                                                                     |
|--------------------------------------------------|--------------------------------------------------------------------------|
| 一瞬悲しい気分になり、やがて消え去った。 | 視界外でペットが命を落としました。                                       |
| ゴボゴボという水音が聞こえる。／コインに水が落ちる音が聞こえる。 | このフロアに泉が存在します。                                             |
| 誰かが万引き犯をののしる声が聞こえる。／レジのチーンという音が聞こえる。 | このフロアに店が存在します。                                             |
| 誰かが金貨を数える音が聞こえる。／巡回中の衛兵の足音が聞こえる。／誰かが探し回る音が聞こえる。 | このフロアに宝物庫が存在します。「数えている」は中にゴールドが残っている証拠であり、「探している」は宝物庫がすでに空であることを示します。 |
| 月に向かって吠える狼の遠吠えが聞こえる。（またはジャッカル） | このフロアのどこかに獣人（ウェアクリーチャー）が生息しています。         |
| 岩が崩れる音が聞こえる。 | 穴掘り生物（ドワーフ、岩モグラ、アンバーハルク）が岩壁を掘削しました。   |
| 近くで／遠くでゴロゴロと鳴る音が聞こえる。 | 視界外で転がる巨石の罠が作動しました。「ゴロゴロという音が唐突に止まった。」は、巨石がテレポートの罠に吸い込まれたことを意味します。 |
| ゴクゴクと音を立てて飲む音が聞こえる。 | モンスターが薬を飲みました（通常は自らの傷の回復）。                     |
| 近くでバチッという発射音が聞こえる。 | モンスターが視界外の何かに向けて杖を振りました。                         |
| 不思議な風の音が聞こえる。 | このフロアに賢者（オラクル）がいます。                                   |
| ジュルジュルという吸い込む音が聞こえる。 | ゼラチンキューブがフロアの床に落ちているアイテムを捕食しました。         |
| バリバリとかみ砕く音が聞こえる。 | 錆の怪物、岩モグラ、またはその他の金属食生物が金属アイテムを食べました。 |
| 起床ラッパが鳴り響いた！ | 兵士がラッパを吹いて周囲の兵士たちを起こしました。戦闘を警戒してください。 |
