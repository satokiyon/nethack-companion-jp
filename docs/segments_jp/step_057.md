#### 識別と状態変化 (Identification and Status Changes) {#identification-and-status-changes}

| メッセージ | 意味 |
|------------|------|
| 喪失感に襲われた。 | 泉にアイテムを浸して解呪の結果を引きましたが、そのアイテムは呪われていませんでした。何も起きておらず、文面とは裏腹に何かを失ったわけではありません。 |
| 喪失感を覚えた。 | 「充填の巻物」を読みましたが、充填できないアイテムを選択してしまいました（杖、指輪、および一部の道具のみが充填可能です）。巻物は無駄に消費されました。 |
| 近くに食料が存在しない気配を感じる。 | 「食料を探す巻物」を読みましたが、フロア内に食料が存在しません。 |
| 物質的に貧しくなった気がする。 | 「金貨を探す巻物」を読みましたが、フロア内にゴールドが存在しません。 |
| 誰かが助けてくれている気がする。 | 「解呪の巻物」を読みました。装備中の呪われたアイテムの呪いが解けました。 |
| 両手が赤く光り始めた。 | 「モンスター混乱」の巻物を読んだか呪文を唱えました。次の近接攻撃が命中すると相手を混乱させます。（すでに混乱している状態で読むと紫色に光ります。） |
| 罪悪感を覚えた。 | 祝福された、または混乱状態で「罰の巻物」を読みました。鉄球と鎖は取り付けられませんでしたが、巻物は識別されました。 |
| あのモードとかいう人物は一体誰だったのだろう？（または「心が内面に向かうにつれて…」） | 「健忘の巻物」を読みました。記憶していた呪文の一部を忘れてしまいました（祝福された巻物なら忘れずに済みます）。 |
| 不安な気分になった... | 呪われた「啓蒙の薬」を飲んだか、上昇できない場所で呪われた「レベルアップの薬」を飲みました。薬は識別され、それ以外の悪影響はありません（啓蒙の薬の場合は賢明のエクササイズ値が少し下がります）。 |
| 偽善者になった気分だ。 | エルベレス（Elbereth）の上に立った状態でモンスターを攻撃しました。刻み文字は消滅し、属性値にペナルティを受けました（実績値が十分に高ければ一律−5、低ければ−1〜−5）。 |
| モンスターたちがあなたの存在に気づいた気配がする。 | モンスターがモンスター怒号（反感）の呪文を唱え、フロア中のモンスターを目覚めさせてあなたに向かわせました。 |
| モンスターたちがあなたの位置を正確に捉えにくくなった気がする。 | 「幻影のクローク」の効果が発動しました。「…正確に捉えにくくなくなった…」は効果が切れたことを意味します。 |
| 遠くで雷鳴がとどろくのが聞こえる... | 自分のペット（または飼い慣らした生物）を殺害しました：属性値−15、幸運値−1。属性値がプラスに戻るまで祈りは失敗します。 |
| 助けが必要な気がする。 | 近くのモンスターがアイテム呪詛の呪文を唱えました：インベントリ内のいずれかのアイテムがランダムに呪われました。使用する前に祭壇などでBUCを確認してください。 |
| 悪の気配を感じる。 | 泉から敵対的な「水の魔神」が召喚されましたが、まだ視界に入っていません。接近してきています。 |
| 誰かが何かを召喚する音が聞こえる... | 司祭系モンスターが視界外で昆虫やヘビを召喚しました。魔法使い系モンスターの召喚では「どこからともなくモンスターが現れた！」と表示されます。 |
| ほんのり温かさを感じた。／ほんのり寒気を感じた。 | 火炎（または冷気）攻撃を受けましたが、自身が持つ内在耐性がそれを吸収しました。自分が思っている通りの耐性を実際に持っていることを確認できる貴重な手がかりです。 |
| ミイラの包帯の下がやけにかゆくなった。 | 透明の巻物、杖、または呪文を使用しましたが、装備中の「ミイラの包帯」が透明化を遮断しました。透明にはなっていませんが、その巻物／杖が透明化であることを確認できました。 |
| 被害妄想が薄らいだ気がした。 | 扉探索の効果によって、マップ上の古い不可視マーカー `I` が消去されました。モンスターがどこへ移動したかまでは分かりません。 |
| 身軽になった気がする！ 反射神経を鍛えたに違いない！（および筋力／知力／賢明／器用／耐久／魅力の各種） | 隠されたエクササイズ（鍛錬）システムによって能力値が上昇しました。何が鍛錬に当たるかは [能力値のエクササイズ (Exercising Your Stats)](#exercising-your-stats) を参照してください。逆に「最近反射神経を鍛えていないようだ」などのメッセージは不摂生（アビュース）が続いたときに表示されます。 |
| 非常に静かに移動できる。 | 「忍びの指輪」またはエルフのクロークを装備しました。（エルフの靴の場合は「非常に静かに歩ける。」となります。） |
| 気分が良くなった！ | 呪われていない「能力回復の薬」を飲み、低下していた能力値が1つ回復しました。 |
| かなり気分が良くなった！ | 祝福された「能力回復の薬」を飲んですべての能力値が回復したか、あるいは魔法の泉の水を飲みました。 |
